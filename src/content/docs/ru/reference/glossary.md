## Три различия, которые важно сохранять

**Запрос — не факт.** В примере интернет-магазина «Списать деньги с покупателя» — запрос. Подтверждённый платёж — свидетельство произошедшего. Тайм-аут оставляет неопределённость; он не доказывает, что списания не было.

**Состояние — не представление для каждого читателя.** Состояние сущности поддерживает решения. Разным читателям могут требоваться разные представления и правила доступа. В примере интернет-магазина итог покупателя и отчёт продавца служат разным целям.

**У прошедшей проверки есть границы.** Компиляция, проверка модели, тесты и проверки песочницы провайдера отвечают на разные вопросы. [Глава о доверии](/ru/start/trusting-your-agent/) объясняет, как объединять их при принятии работы агента.
